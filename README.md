## 🛠️ How to Compile & Run

You can compile and run any C program in this repository using **GCC** or **Clang** in your macOS/Linux terminal.

### 1. Compile
```bash
gcc Module-1/zero_non_zero_problem.c -o output
```

### 2. Run
```bash
./output
```

## 🛠️ Git Commands to Push Code

If you want to initialize and push this project to your GitHub repository (`c-problem-solving`), follow these commands in your terminal:

```bash
# 1. Initialize Git repository
git init

# 2. Add remote repository URL
git remote add origin https://github.com/Chironjit598/c-problem-solving.git

# 3. Rename branch to main
git branch -M main

# 4. Fetch existing commit from remote (if remote has README)
git pull origin main --rebase

# 5. Add all files
git add .

# 6. Commit your changes
git commit -m "Add Module-1 problems and updated README"

# 7. Push to GitHub
git push -u origin main
```
